**`engine/fx.py`.** A local `StrictModel`, module-anchored `FX_DIR = Path(__file__).resolve().parents[1] / "data" / "fx"`, an `FxSnapshot` Pydantic model, and `load_fx_snapshot(base, quote)` that builds the filename from the two currency codes only after validating each against a closed committed tuple of supported codes — never interpolating an arbitrary string into a `Path`. Reject a rate that is zero, negative, or non-numeric at load time.

`convert(amount: Decimal, base: str, quote: str) -> Figure` mirrors `engine.net_cash.transferable`'s refusal shape exactly:
- A missing snapshot raises `ValueError` naming both currencies and stating that the conversion is refused rather than derived through a third currency (D-74).
- `base == quote` returns the amount unchanged in a Figure whose derivation says no conversion was applied.
- The reverse direction is NOT served by inverting a committed rate. A `usd-gbp` conversion requires a `usd-gbp` snapshot; if none exists it raises with the same refusal message. An implicit inversion is the same class of invention as a cross-rate.
- The returned Figure has `value = quantize_money(amount * Decimal(snapshot.rate))`, `unit` equal to the quote currency, `basis="sourced"`, `confidence="researched"`, `source_url` and `date_checked` from the snapshot, and derivation lines naming the input amount, the base currency, the rate, the snapshot's `as_of_date`, and the fact that the rate is a committed dated snapshot rather than a live quote.

Also expose `rate_figure(base, quote) -> Figure`, returning the rate itself as its own cited Figure with `unit` set to the pair label — this is the object D-75's currency component of the gap decomposition attaches to in plan 04-06.

**`tests/test_engine_fx.py`** covers: the missing-pair refusal and its message; the no-implicit-inversion refusal; identity when base equals quote; a rate of exactly `"1"` returning the input amount unchanged; a zero and a negative rate rejected at load; a product landing on a half-dollar boundary rounding up under the pinned ROUND_HALF_UP rather than the ambient default; and a case proving a single quantize is applied (constructed so that quantizing twice would differ by one unit).
