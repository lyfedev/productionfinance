**`engine/per_diem.py` — the snapshot reader.** A local `StrictModel`, a module-anchored `PER_DIEM_DIR = Path(__file__).resolve().parents[1] / "data" / "per_diem"`, Pydantic models for a per-diem table, and `load_per_diem(per_diem_id)` resolving through a committed `PER_DIEM_PATH_BY_ID` dict — a visitor string never reaches this function, and the id is compared by plain string equality with no normalization. `month_weighted_per_diem(table, calendar, headcount) -> Figure` multiplies each month's nights by that month's lodging rate plus `mie_daily`, sums in `Decimal`, and quantizes once through `quantize_money`.
