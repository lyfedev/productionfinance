**`data/city_geo.yaml`** — a committed cartographic reference table, one entry per
committed cost profile (`us-ny-new-york`, `us-ca-los-angeles`, `gb-london`). Each entry
carries `city_id`, `label`, `latitude`, `longitude`, `source_url`, `date_checked` and
a `note` explaining what the coordinate refers to (a city centroid, not a production
office). Every numeric value is a quoted YAML string, matching RD-01's convention used
by every other file under `data/`. The header states plainly that these are reference
coordinates for map placement and are not a priced figure. Cite a real, retrievable
source URL per coordinate — a coordinate with no source URL is not committed.

**`engine/city_geo.py`** — mirror `engine/cost_profile.py`'s discipline exactly: a
`CityGeo` Pydantic model over a `StrictModel` base that forbids extra fields, a
module-anchored `CITY_GEO_PATH` constant built from `Path(__file__).resolve().parents[1]`
(never CWD-relative — the systemd unit sets `WorkingDirectory=/opt/prodfin`), and a
single `load_city_geo()` read path using `yaml.safe_load` only. Expose
`geo_for_city_id(city_id) -> CityGeo | None`; a city with no committed coordinate returns
`None` and is omitted from the map. Never interpolate a visitor string into a path and
never derive a coordinate.

**`app/services/compare.py`** — the compare surface's own service layer. It calls
`app.services.spec.handle_spec_submission` and holds no pricing logic of its own
(mirroring `app/routers/spec.py`'s own no-business-logic contract). It exposes:
  - `CompareInputs` — a Pydantic model of the query-string form of a comparison
    (`production_type`, `shoot_days_stage`, `shoot_days_location`, `crew_size`,
    `crew_tier`, `principal_cast_count`, `principal_cast_imported_count`,
    `crew_imported_count`, `crew_hired_locally_count`, `start_quarter`, `start_year`,
    `candidate_cities`, `reporting_currency`), with `extra="forbid"` and sane defaults
    so a bare `GET /compare` renders a real default comparison rather than an error.
  - `build_comparison(inputs) -> Comparison` — resolves the inputs to a `SpecResult`,
    then assembles the render-ready view model: the two bands in `engine.ranker.rank`'s
    own order, the unpriced-city list, the GeoJSON feature collection, and the value
    range used for the colour ramp.
  - `to_geojson(ranked_cities, unpriced) -> dict` — a GeoJSON `FeatureCollection`. Each
    feature's `properties` carries `city_id`, `label`, `band`, `total_value` (a float,
    for MapLibre's interpolate expression only), `total_text` (the exact `Decimal` string
    plus unit, for display) and `reason`. **A feature in the `incentive_not_modelled`
    band carries no `total_value` property at all** — MapLibre must not be able to place
    it on the net-cost ramp even by accident.
  The `total_value` float is a display-layer input to a colour expression and nothing
  else. Every figure a visitor reads comes from the `Decimal` string, never the float.

**`app/routers/compare.py`** — `@router.get("/compare", response_class=HTMLResponse)`
taking the `CompareInputs` fields as query parameters, plus
`@router.post("/api/v1/compare")` returning the same comparison as JSON built with
`engine.figure_serialize.figure_to_dict` (never `dataclasses.asdict`, which crashes on
`Decimal`/`date`). Follow `app/routers/spec.py`'s established shape: import
`PUBLIC_PATH` and `templates` from `app.main` inside the handler, not at module import.
Malformed query values return a readable 422 with the reason, never a 500 and never a
bare framework error page.

**`app/main.py`** — mount `StaticFiles(directory=Path(__file__).resolve().parent /
"static")` at `/static` and include the compare router. Anchor the directory to the
module, not the CWD, for the same reason `templates` already is.

**`app/templates/compare.html`** — extends `base.html`. Server-renders, in this order:
the comparison's inputs as read; a `<div id="map">` container; the two-band ranked list
via `{% include "_ranked_list.html" %}` (Task 3 owns that partial's full content — create
it in this task with the ranked band rendering so the tracer is genuinely end to end);
and the map legend. **Progressive enhancement is a hard requirement:** every figure a
visitor needs is in the server-rendered HTML before any script runs. The map container
carries a `<noscript>` block naming that the map is an enhancement and that the full
ranking is in the list below it.

**MapLibre** loads as a plain `<script>` tag from a CDN (`maplibre-gl@6.5.0`) with its
stylesheet, no build step, no bundler, no npm. The basemap style URL is
`https://tiles.openfreemap.org/styles/liberty` — no API key, no account. Pass the GeoJSON
to the page as a `<script type="application/json" id="compare-geojson">` block rather
than by string-interpolating JSON into executable JavaScript.

**`app/static/compare.js`** — reads that JSON block, constructs the map, adds the
GeoJSON source and a `circle` layer whose `circle-color` is a MapLibre `interpolate`
expression over `total_value` and whose `circle-radius` scales with the same property.
It guards on `document.getElementById("map")` being present and on MapLibre having
loaded; a failed CDN load leaves the server-rendered page fully usable. Bind a popup per
marker showing the city label, its band, and its total as the exact `total_text` string.

**`app/static/prodfin.css`** — the project's design system, written once, here.
Establish: a type scale with a real display face for headings and a tabular-figure
numeric face for every money value (`font-variant-numeric: tabular-nums` so columns of
figures align); a restrained colour system with an explicit sequential ramp for the
net-cost scale and a separate, deliberately non-scale neutral treatment for the
unranked band; consistent spacing tokens as CSS custom properties; and a layout that
puts the map and the ranked list side by side on wide viewports and stacked on narrow
ones. This is judged design work — make it look like a considered product, not a
default stylesheet. Keep every class name clear of the D-70 vocabulary list.

**Tests** — `tests/test_engine_city_geo.py` covers the loader (round-trip, an unknown

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| anonymous browser -> `GET /compare` query string | Every input is attacker-controlled: city strings, integers, currency code, quarter. No auth precedes it. |
| service -> filesystem (`data/cost_profiles/`, `data/city_geo.yaml`) | A visitor-supplied city string must never become a filesystem path component. |
| server -> rendered HTML + embedded GeoJSON | Visitor strings are echoed back into two different contexts (HTML text and a JSON script block) with different escaping rules. |
| browser -> third-party CDN (MapLibre) and tile host (OpenFreeMap) | Third-party script execution and third-party network requests inside the product page. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-01 | Tampering | `engine/city_geo.py` path construction | high | mitigate | `city_id` is only ever a key looked up in the parsed committed table; a visitor string is never joined to `CITY_GEO_PATH`. Mirrors `engine/city_profile_lookup.py`'s existing allow-list-only discipline. |
| T-06-02 | Information disclosure | reflected candidate-city strings in HTML | high | mitigate | Jinja2 autoescaping stays on (never `\|safe` on a visitor string); asserted by a script-tag test in Task 3. |
| T-06-03 | Information disclosure | reflected candidate-city strings inside the embedded GeoJSON `<script type="application/json">` block | high | mitigate | GeoJSON is emitted as a non-executable `application/json` script block and escaped for that context, never string-interpolated into executable JavaScript. Asserted by the same Task 3 test. |
| T-06-04 | Tampering | third-party MapLibre CDN script | medium | mitigate | Pin the exact version in the URL and add a Subresource Integrity `integrity` attribute plus `crossorigin="anonymous"`, so a mutated CDN payload fails closed. The server-rendered ranking remains fully readable if the script fails to load. |
| T-06-05 | Denial of service | unbounded `candidate_cities` list | medium | mitigate | Cap the accepted candidate-city count in `CompareInputs` with a Pydantic validator and return a readable 422 above the cap; each city costs a real pipeline run. |
| T-06-06 | Denial of service | `StaticFiles` mount | medium | mitigate | Mount a module-anchored directory containing only the project's own CSS/JS; never mount a repo root or a user-writable path. |
| T-06-07 | Information disclosure | error responses on malformed query values | low | mitigate | Malformed input returns a readable 422 naming the field, never a stack trace, matching `app/routers/spec.py`'s existing handling. |
| T-06-08 | Spoofing | OpenFreeMap tile host availability/content | low | accept | Basemap tiles are decorative context; every figure is server-rendered text. A tile outage degrades the page's look, not its truth. Accepted rather than self-hosting tiles, which would add real infrastructure for no gain in figure integrity. |
| T-06-SC | Tampering | npm/pip/cargo installs | high | mitigate | This plan installs no package. `pyproject.toml` is unchanged, MapLibre arrives as a CDN `<script>` tag with SRI rather than an npm dependency, and `lockfile-scan.sh` runs in Task 3's verify. Any package install would require a RESEARCH.md Package Legitimacy Audit entry and a blocking human checkpoint first. |
</threat_model>
