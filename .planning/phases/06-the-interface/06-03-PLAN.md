# Plan 06-03 — provenance: every number opens its own source

## Objective

Deliver UI-06, PRV-04 and PRV-05. This is the plan that makes the repo's central
claim visible in the product: every figure is sourced, dated, and inspectable.

## Why this is the honesty spine

The project brief's core value is "every figure sourced, dated, and provably
matching what a government actually paid." Phases 1-5 made that structurally true
in the data — each figure carries its citation in the same record as the number.
This plan is where that becomes visible to a visitor rather than only to someone
reading YAML in the repo.

## Tasks

### Task 1 — a reusable figure partial

Build `app/templates/_figure.html` plus `app/services/provenance.py`: one
component that renders a money figure together with a path to its rule, source
URL and date-checked.

**A figure with no reachable provenance must not render as a bare number.** It
renders with an explicit "provenance unavailable" state naming what is missing.
A bare number is indistinguishable from a sourced one at a glance, which is
exactly the confusion the product exists to remove.

Show the `basis` axis (D-58/D-59) and, separately, `Figure.confidence`
(validated | researched). These are different questions — *where did this number
come from* versus *has it been checked against a government disclosure* — and
RD-02 says they are never conflated. Two labels, never merged into one badge.

`<verify>`: a test walks the rendered comparison HTML, finds every money figure,
and asserts each has either a provenance link or an explicit unavailable state.
No bare numbers.

### Task 2 — the consolidated printable assumptions panel (PRV-04)

`app/templates/assumptions.html`: every rate used in the current comparison,
each with its own source URL and date-checked, plus the D-60 acknowledged-gaps
list naming what the model does not price.

Printable means a real print stylesheet — legible page breaks, visible URLs,
no clipped tables. A producer hands this upward.

`<verify>`: for a known comparison, assert the panel lists exactly the rates the
engine actually used — derived from the Figure tree, not a hand-maintained list
that can drift.

### Task 3 — the methodology page (PRV-05)

`app/routers/methodology.py` + `app/templates/methodology.html` at a stable
linkable URL, explaining how figures are computed: the stages, what is sourced
versus modelled, what the honest-refusal states mean, and why an unmodelled
incentive is unknown rather than zero.

It must persist independently of any comparison — a link someone can send.

## Prohibitions

Never fabricate a source URL or a date-checked to make the panel look complete.
An absent citation is rendered as absent.
No React, no Vite, no build step.
`.github/scripts/vendor-scan.sh` cannot tell a comment from a call site.
