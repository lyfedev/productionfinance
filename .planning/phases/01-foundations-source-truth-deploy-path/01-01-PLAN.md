Module-level constants: `BOOT_TIME` computed once at import as a timezone-aware UTC ISO-8601 string, and `GIT_SHA` resolved by a module-level function that reads `PRODFIN_GIT_SHA` from the environment, falls back to `git rev-parse --short HEAD` via `subprocess` inside a guard, and falls back again to the literal `unknown` — the resolution path must never raise, because an unresolvable SHA on the host must not stop the service from booting. Assert the /health status code, the exact key set, `status == "ok"`, that `version` matches `app.__version__`, that `boot_time` parses as an ISO-8601 datetime carrying UTC offset information, that two consecutive /health calls report the same `boot_time`, and that `git_sha` is a non-empty string. Assert GET / returns 200 with `ProductionFinance` in the body.

Poll `/health` up to 20 times at 0.5s intervals. Assert HTTP 200 on `/health`, assert the response body carries `git_sha` and `boot_time`, assert HTTP 200 on `/`, print each assertion result, and exit non-zero on any failure. `set -eu` at the top. Make it executable.

Run `uv sync` so `uv.lock` is generated and committed.
