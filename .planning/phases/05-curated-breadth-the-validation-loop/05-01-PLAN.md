government PDF and Parallel Extract is the only permitted way to read one.

Stage One gates; everything else in this project is a quality axis behind them.

end-to-end run and prints a real number the existing engine computed.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| process env → agent code | API key material enters the process; it must never leave it via a log, an error, a template or an artifact |
| agent code → Parallel API | outbound call to a third-party service over the network |
| Parallel Search result → Extract | an attacker-influenceable URL (search results are not curated) crosses into a fetch |
| Extract markdown → Gemini prompt | untrusted third-party document text crosses into an LLM prompt |
| Gemini output → engine + templates | model-generated strings and numbers cross into `Decimal` arithmetic and rendered HTML |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
