  <behavior>
    - A quote that appears verbatim in the document text is grounded.
    - A quote that differs from the document only by whitespace runs, a non-breaking space, or surrounding table-cell punctuation is still grounded — normalization is applied to both sides before comparison.
    - A quote that appears nowhere in the document text is ungrounded, and the returned verdict carries a reason naming what was not found.
    - A quote that does appear, but whose reported money figures do not appear inside that quote, is ungrounded — a figure must be present in the passage it claims to come from.
    - An empty or whitespace-only quote is ungrounded.
    - `run_job1` turns an ungrounded award into an `ExtractionFailure` carrying the guardrail's name and the quote prefix, prices nothing for it, and constructs no substitute award.
    - `AccuracySummary` gains no new field: a rejected award raises the existing extraction-failure count and nothing else.
  </behavior>
  <action>
    Create `agent/groundedness.py`. Export a frozen dataclass `GroundednessVerdict` with `grounded: bool`, `reason: str` and a truncated `quote_prefix: str`, and a pure function `check_grounded(quote, document_text, figures)` returning it. The function takes only strings already in memory, imports nothing from `engine/`, imports no SDK, and performs no I/O.

    Normalize both sides identically before comparing: case-fold, map the non-breaking and narrow non-breaking space characters to an ordinary space, collapse runs of whitespace to a single space, and strip the pipe and dash characters a markdown table cell wraps a value in, from both ends only. Then test that the normalized quote is a substring of the normalized document. Normalization is a deliberate loosening of an exact match and must be documented in the module docstring as such, with the reason: an extractor reading a table returns the cell's text, not the document's byte-exact row framing, and rejecting on framing alone would reject genuine rows.

    Apply the same normalization to each supplied figure string and require each to be a substring of the normalized quote. This is what makes the check bite: a passage that exists but does not contain the number attributed to it is exactly the failure mode a groundedness check is for.

    Wire it into `agent/job1.py`. Thread the extracted document's text into the per-award loop — `run_job1` already holds the `DisclosureDocument`; pass its text into `_price_and_classify_award` as a keyword argument with no default so no caller can accidentally skip the check. Run the check before parsing figures and before pricing. On an ungrounded verdict return an `ExtractionFailure` whose `production_title` is the award's title, whose `raw_value` is the verdict's quote prefix, and whose `error` names the groundedness guardrail and the verdict's reason. Do not add a bucket to `AccuracySummary` — D-86 forbids a percentage, mean, blended or aggregate-error field there, and the existing extraction-failure count is the honest home for a rejected award.

    Fix the offline loop. `tests/test_agent_job1_offline.py` drives the whole pipeline from committed fakes; its fake awards' quote strings must now genuinely appear in `tests/fixtures/agent/esd_excerpt_double.md`, or the offline expected bucket counts change.     Add the groundedness tests to `tests/test_agent_guardrails.py` (Task 3 creates that module's docstring and registry; if it does not exist yet, create it here with the tests and let Task 3 fill in the rest).

Export a closed `EnactmentStatus` string enum with exactly the members `enacted`, `proposed` and `unknown`; a frozen `EnactmentVerdict` dataclass carrying `status`, `matched_markers` (a tuple of marker names), and `evidence` (a tuple of matched excerpts, each truncated); and a pure function `classify_enactment(url, text)` returning a verdict. Populate it in `run_job1` immediately after Extract returns a usable document, classifying from the document's URL and text. Extend `agent/runs.py`'s save to serialize the verdict and its load to deserialize it, defaulting to `None` for a run file written before this change so an old artifact on disk loads rather than raising. Preserve the existing rule that a non-live run's awards and accuracy never enter the render context; the enactment verdict is a property of the source document, so it may render for any run that reached Extract, but it must never be used to imply a figure was validated.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| model output -> priced figure | A string the model authored becomes a number compared against a government disclosure |
| search result -> source of record | A ranked web result becomes the document a rule or figure is read from |
| source document -> legal claim | A document's text becomes an assertion about what the law is |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-28 | Spoofing | model-authored quotes | critical | mitigate | `agent.groundedness.check_grounded` requires the quote and each reported figure to be present in the extracted document; an ungrounded award becomes an extraction failure and is never priced |
| T-05-29 | Spoofing | search-result host | high | mitigate | only a parsed hostname suffix-matching a government domain is accepted; a government-looking string in a path or query is rejected, asserted directly in the new gate |
| T-05-30 | Tampering | prompt injection inside a fetched document | high | mitigate | both new modules are pure functions over strings with no tool access; the extraction call remains structured-output-only with no tool-selecting loop, so document text cannot reach an action |
| T-05-31 | Repudiation | legal status of a cited source | high | mitigate | `agent.enactment.classify_enactment` records the matched marker and excerpt on the verdict, persists it with the run, and renders it — a rate read from a bill is visibly distinct from a rate read from enacted law |
| T-05-32 | Information disclosure | rendered run artifacts | medium | mitigate | the enactment verdict carries truncated excerpts of a public government document only; the existing rule that a non-live run's awards and accuracy never enter the render context is preserved |
| T-05-SC | Tampering | package-manager installs | high | accept | this plan installs no package; `pyproject.toml` and `uv.lock` are not in `files_modified` and `.github/scripts/lockfile-scan.sh` remains the standing gate, re-run in Task 3 |
</threat_model>
