<objective>
JUR-04: Connecticut's rule model becomes genuinely validated against the
Connecticut open data CSV — every one of its three declared statutory rate bands
proven against a real disclosed award drawn from that CSV, and the model's one
honest refusal made a permanent, named, asserted behaviour instead of a
footnote.

staged, reduced, or conditional. The ROADMAP's "cut line" naming Connecticut as
the first cuttable item is void for the same reason.

but only the top band has ever been exercised by a committed pair. A model whose
two lower bands have never been run against a real government figure is a
researched model, not a validated one. This closes that gap from the same
archived CSV the model was derived from.

Output: two new Connecticut validation pairs covering the unexercised bands; a
Connecticut-specific test module asserting literal expected values and full band
coverage; a restated `transfer_discount` note making the refusal explicit.
</objective>
