<objective>
Widen the 05-01 tracer from one award to the whole disclosure, and give the run an honest
accuracy figure.

This closes AGT-01 (ingest a published government disclosure and extract every
production/award pair), AGT-02 (re-run the model against each pair and report accuracy),
AGT-03 (reproduce at least three published award figures exactly) and AGT-04 (the explicit
three-value mismatch taxonomy, built in now rather than retrofitted — D-86).

Two constraints shape everything here. D-85: extracted pairs re-run through the EXISTING
engine with no new code path, so `engine/` gains not one line this phase — the engine must
not know or care whether a pair came from a committed YAML fixture or from Gemini. D-87: an
extraction that returns nothing usable is a legitimate reported outcome; a fabricated award
pair inside an accuracy figure is precisely the dishonesty this product exists to prevent.

Purpose: an accuracy figure that can be trusted is the entire product claim. A blended
percentage that can silently absorb a real bug is worse than no figure at all.
Output: a `Job1Run` carrying per-award verdicts and three honest bucket counts.
</objective>
