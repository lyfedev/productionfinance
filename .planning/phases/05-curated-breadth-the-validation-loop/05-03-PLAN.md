**`agent/telemetry.py`.** Extend `sdk_call` with an optional `collector: list | None`
parameter. When given, append the same record it logs — sdk, op, target, elapsed_ms,
outcome, UTC timestamp — as a plain dict. The logged line and the on-page evidence must be
the SAME record, not two independently-produced claims (D-84). Never add a key, a prompt or
document text to the record.

**`agent/job1.py`.** Thread a `collector` list through the run so `Job1Run` carries
`sdk_calls`. Add an optional `on_stage(stage: str)` callback invoked as the run enters each
stage — searching, extracting, reading, pricing — so the page can name what is happening
instead of showing a bare spinner.

**`agent/runs.py`.** JSON persistence for a run:
  - `RUNS_DIR = REPO_ROOT / "var" / "job1"` (created on demand) and
    `COMMITTED_RUNS_DIR = REPO_ROOT / "runs" / "job1"`.
  - `run_to_dict(run)` — every `Decimal` via `str(...)`, every enum via `.value`, no
    environment, no key, no raw prompt. A `Figure` is serialised with the existing
    `engine.figure_serialize.figure_to_dict`, not a second serialiser.
  - `save_run(run)` writes `var/job1/{run_id}.json` and rewrites `var/job1/latest.json`.
  - `load_run(run_id)`, `load_latest()`, and `newest_committed_run()`.
  - `run_id` is a `uuid4().hex`. `load_run` validates it against a strict 32-hex-character
    pattern BEFORE building any path — the id arrives from the URL and an unvalidated one
    reaching an `open()` is a traversal (threat T-05-12). This mirrors the closed-allowlist
    check `app/services/validate.py::reproduce_disclosure` already performs on `pair_id`.
  - Add `var/` to `.gitignore`. `runs/` stays tracked — it is the committed evidence
    directory Phase 8 reads.

**`app/routers/job1.py`.** Business logic in one place, two views (D-43), mirroring
`app/routers/validate.py`:
  - Module-level `threading.Lock`, an in-process `dict` of run states, and
    `MIN_SECONDS_BETWEEN_RUNS` from `PRODFIN_JOB1_MIN_INTERVAL_S` defaulting to 60.
  - `GET /job1` — render the newest run from `var/job1/latest.json`, falling back to
    `newest_committed_run()`, falling back to an empty state. Always render the trigger
    form. When `integration_status()` reports a missing key, render its message instead of
    the form; do not disable the page.
  - `POST /job1` — refuse politely and legibly when unconfigured, when a run is already in
    flight (single-flight lock), or when the minimum interval has not elapsed; the JSON
    view answers 429 for the last two, the HTML view renders the reason and the seconds
    remaining. Otherwise mint a run id, record `status=running` with the current stage,
    start a `daemon=True` `threading.Thread` that calls `run_job1(...)` with the stage
    callback and then `save_run`, and return a 303 redirect to `{PUBLIC_PATH}/job1/{run_id}`. The pipeline takes tens of seconds; holding a
    synchronous request open across the Apache proxy timeout would show a judge a broken
    page (threat T-05-04).
  - `GET /job1/{run_id}` and `GET /api/v1/job1/{run_id}` — same handler output, two views.
    Unknown id is a 404 with a readable detail.
  - **The non-live refusal.** Before rendering any accuracy figure, assert
    `run.run_mode == "live"`. A run in any other mode renders a loud banner stating that it
    was a replay and carries no accuracy claim. Enforce this in the router, not only in the
    template — a template rewrite must not be able to drop it.

**`app/templates/job1_result.html`.** Extends `base.html`. Show, in this order: the terminal
state or the named in-flight stage; the search objective and the document URL Search
returned with its primary-government-domain check shown as passed; the document sha256 and
character count, plus a visible truncation notice when the document was sliced; the three
taxonomy bucket counts as counts with the denominator, never as a percentage (D-86); a
table of every award with disclosed, computed, verdict, and — for an explained variance —
the rule id, reason and source link; and an evidence block listing the run's
`PRODFIN_SDK_CALL` records. Every unexplained row must appear in the table; none may be
collapsed or hidden behind a toggle. While the run is in flight, include a
`meta http-equiv="refresh"` of 3 seconds and drop it once terminal. Jinja2 autoescaping is
on by default and must not be disabled anywhere — model-produced strings are rendered here
(threat T-05-13).

**`app/main.py`** — include the new router. **`app/templates/index.html`** — add a third
section linking `{{ public_path }}/job1` with a one-paragraph description in the same voice
as the existing two.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| anonymous visitor → FastAPI | an unauthenticated POST can trigger paid third-party API calls |
| URL path segment → filesystem | `run_id` from the URL is used to locate a run artifact |
| model-produced strings → rendered HTML | extracted titles and reasons are injected into a template |
| repository → live host | `git pull` on the box is the deploy mechanism for a public site |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-04 | Denial of service | `POST /job1` | high | mitigate | Single-flight `threading.Lock` plus `MIN_SECONDS_BETWEEN_RUNS` (default 60) bound anonymous-triggered spend and concurrency; per-stage timeouts and `MAX_DOCUMENT_CHARS` from 05-01 bound one run; the background thread keeps the Apache proxy timeout from being held open |
| T-05-12 | Tampering | `agent/runs.py::load_run` | high | mitigate | `run_id` is validated against a strict 32-hex-character pattern BEFORE any path is built, mirroring the closed-allowlist check `app/services/validate.py` already applies to `pair_id`; the untrusted string never reaches `open()` |
| T-05-13 | Elevation of privilege | `app/templates/job1_result.html` | high | mitigate | Jinja2 autoescaping is on by default and is never disabled; a route test asserts a script tag in an extracted title renders as escaped text |
| T-05-14 | Information disclosure | run artifacts and the JSON view | critical | mitigate | `run_to_dict` serialises no environment and no key; `/health` is unchanged; a route test asserts no key value appears in the JSON payload; `.gitignore` covers `var/` and already covers every `.env*` path |
| T-05-15 | Spoofing | a replay run shown as an accuracy figure | critical | mitigate | The router refuses to render an accuracy figure unless `run_mode == "live"`, enforced before the template and covered by a test — a test double can never become a published claim |
| T-05-16 | Repudiation | production evidence for SHP-05/SHP-06 | critical | mitigate | The verbatim `journalctl` transcript plus the committed `runs/job1/` artifact are the record; when they cannot be produced, the gap is written to `.planning/WINDOWS.md` rather than left implicit |
</threat_model>
