# Plan 08-03 — the submission artifacts and the ship checklist

## Objective

Produce the written description, the demo script, and the cold-verification
checklist — and re-run the gates rather than trusting their earlier passes.

## Tasks

### Task 1 — the written description (SHP-12)

`docs/SUBMISSION.md`: features, technologies, data sources, findings.

**Every claim must be checkable:**
- Technology claims verify against `uv.lock`. Do not list a library the tree
  does not resolve.
- Data-source claims name an archived artifact in `sources/MANIFEST.yaml` with
  its sha256. "We use GSA per diem data" is weaker than naming the committed
  file and its hash.
- Findings are the real numbers the validation loop produced — including
  residues and refusals. New Jersey's *Joker* residue of exactly
  `Decimal("122665")` explained by a sourced 2% diversity bonus is a stronger
  finding than a round accuracy claim.

**State what is not met.** If AGT-03, SHP-05 or SHP-06 remain unproven for want
of credentials, say so. The repo is public and inspectable; a description that
overclaims is checkable against the tree in minutes.

### Task 2 — the demo script (SHP-11)

`docs/DEMO-SCRIPT.md`: a shot list for ≤3 minutes, pain landed in the first 15
seconds, sequencing the four beats (reproduce a government figure → naive
arithmetic is wrong → ranking inverts → live research labelled unvalidated).

The video is a human deliverable. This plan produces the script and shot list,
not the recording.

### Task 3 — the pre-submission gate and cold-verification handoff (SHP-13, D-103)

`scripts/pre_submission_check.sh` — re-run, do not cite:
- `.github/scripts/lockfile-scan.sh` and `vendor-scan.sh`
- `scripts/audit_sdk_call_sites.py --check` (D-96)
- the full pytest suite
- the grep checklist from CLAUDE.md over the source tree
- SHP-14 non-vacuity: break a rule value, confirm the suite catches it, revert.
  **Prove it this run.** A gate that passed earlier is not evidence about the
  current tree.
- grep production logs for one real Gemini call and one real Parallel call
  fired by a live logged-out session

`.planning/SHIP-CHECKLIST.md` — the human handoff, explicitly marked as actions
no agent can perform:
1. Install `PARALLEL_API_KEY` and `GEMINI_API_KEY` in `/opt/prodfin/.env`
   (mode 600, owner `prodfin`), restart the service
2. Trigger `/job1` and `/research` from a logged-out browser
3. Re-grep `journalctl -u prodfin` for `PRODFIN_SDK_CALL`
4. Commit the resulting `runs/` artifacts and close WINDOWS #26/#28
5. Record the demo video
6. **Last:** open the hosted URL from a logged-out browser on a different
   network than the development machine and confirm it works

Each item unchecked until genuinely done. Do not pre-tick a human step.

## Prohibitions

Never claim a capability the tree does not have.
Never mark a human step complete on the human's behalf.
`.github/scripts/vendor-scan.sh` cannot tell a comment from a call site.
